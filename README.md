## 💡 Como Usar

### Interface Intuitiva em 3 Passos

<table>
<tr>
<td width="33%" align="center">
  <h4>1️⃣ Defina o Período</h4>
  <p><b>Horário de Início:</b> HH:MM<br>(ou deixe em branco para usar a hora atual)</p>
  <p><b>Duração:</b> Ex: <code>2:30</code> ou <code>2.5</code><br>(2 horas e 30 minutos)</p>
</td>
<td width="33%" align="center">
  <h4>2️⃣ Liste as Atividades</h4>
  <p>Digite suas atividades separadas por vírgula</p>
  <p>Exemplo:<br><code>Estudar, Exercício, Lazer, Trabalho</code></p>
</td>
<td width="33%" align="center">
  <h4>3️⃣ Gere o Gráfico</h4>
  <p>Clique em <b>"Gerar Gráfico"</b></p>
  <p>Visualize seu tempo no relógio analógico</p>
  <p>O gráfico é salvo automaticamente como PNG</p>
</td>
</tr>
</table>

### 📝 Formatos Aceitos

| Campo | Formato | Exemplos Válidos |
|-------|---------|------------------|
| **Horário de Início** | `HH:MM` ou vazio | `14:00`, `08:30`, _(vazio para hora atual)_ |
| **Duração Total** | `HH:MM` ou decimal | `3:00`, `1:30`, `2.5`, `0:45` |
| **Atividades** | Texto separado por vírgula | `Estudar, Descansar, Trabalhar` |

## 🎯 Exemplo Prático

### Cenário: Planejando uma Tarde Produtiva

```
📍 Horário de Início: 14:00
⏱️ Duração Total: 4:00
📋 Atividades: Estudar Python, Exercício Físico, Projeto Pessoal, Leitura
```

**Resultado:**
- **14:00 - 15:00**: Estudar Python _(setor azul)_
- **15:00 - 16:00**: Exercício Físico _(setor verde)_
- **16:00 - 17:00**: Projeto Pessoal _(setor laranja)_
- **17:00 - 18:00**: Leitura _(setor roxo)_

O programa gera um relógio colorido mostrando cada atividade como um setor, com os horários claramente marcados e uma legenda explicativa.

## 🔧 Como Funciona

### Arquitetura do Sistema

```
┌─────────────────────────────────────────────────────┐
│                  Interface Gráfica                   │
│                      (Tkinter)                       │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│              Processamento de Dados                  │
│  • Validação de entradas                            │
│  • Conversão de formatos de tempo                   │
│  • Cálculo de divisões                              │
│  • Conversão horário → ângulos                      │
└────────────────────┬────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────┐
│              Geração do Gráfico                      │
│                  (Matplotlib)                        │
│  • Desenho do relógio analógico                     │
│  • Setores coloridos para cada atividade            │
│  • Anotações e legendas                             │
│  • Exportação para PNG                              │
└─────────────────────────────────────────────────────┘
```

### Principais Componentes

#### 1. **Validação Inteligente**
- ✅ Verifica formato de horários (`HH:MM`)
- ✅ Aceita múltiplos formatos de duração (`1:30`, `1.5`)
- ✅ Detecta atividades duplicadas
- ✅ Mensagens de erro claras e orientativas

#### 2. **Cálculo Preciso**
- Divide o tempo total igualmente entre as atividades
- Calcula horários de início e término usando `datetime`
- Converte horários em ângulos para representação no relógio (360° ÷ 12h = 30°/hora)

#### 3. **Visualização Profissional**
- Relógio analógico com marcações de hora
- Paleta de cores automática e distinta para cada atividade
- Anotações com horários posicionadas estrategicamente
- Legenda clara e informativa
- Exportação em alta resolução
